# trip-receipt — 旅費精算帳

スマホで使う旅行費用の精算アプリです。ビルド不要の静的ファイル (`index.html`) だけで動きます。

## できること

- 費用を **ホテル / ツアー / 移動 / 現地** の4分類で記録 (名称・金額・通貨)
- 割り勘: 新規入力時はオフ。オンにすると全員が選ばれる。支払い者を選び、参加者ごとの個人金額を「均等」または「個別に入力」で設定
- キャンセル: 予約をキャンセルした費用はキャンセル料だけを精算に含める (割り勘の割合はそのまま)
- 自由入力欄: 分類ごとに「場所」(ホテル)・「内容・集合場所」(ツアー)・「手段」(移動)・「食事場所・お土産など」(現地)。移動と現地は候補をタップして入力可能
- 通貨レートは **旅行開始日のレートで固定**。設定画面の「開始日のレートを取得」で
  frankfurter.dev (欧州中央銀行の参照レート) から取得、または手入力
- 精算画面: 誰が誰にいくら払えばよいか、メンバー別の立替/負担、カテゴリ別合計
- 確認チェック: 費用の入力画面の「確認済み」スイッチで記録 (一覧には「✓ 確認済み」と表示)。精算画面の各送金は丸をタップで「支払い済み」
- 並び替え: 新しい順・古い順・金額順・名前順・未確認を先に・手動 (▲▼で移動)
- 入力内容はアプリ内 (ブラウザの localStorage) に自動で残り、次回起動時に続きから再開
- 保存ファイル: 画面上部のファイル表示から `.json` ファイルとして保存・読み込み
  - 画面上部に「開いているファイル名」と状態 (未保存 / 保存済み / 変更あり / 自動保存) を常に表示
  - 画面上部の「保存」ボタンで1タップ保存 (パソコンでは Ctrl+S / ⌘S)
  - Chrome・Edge (パソコン): 保存先フォルダを選べ、以後はそのファイルに自動で上書き保存
  - iPhone: 共有メニューの「"ファイル"に保存」で iCloud Drive などの場所を選択
  - Android など: ダウンロードフォルダに保存
  - データを文字としてコピー / 貼り付けすることも可能
- メンバーと共有: ファイル画面の「メンバーと共有する」から
  - **共有リンクを送る**: 旅行のデータ (メンバー・費用・レート) をすべて入れたリンクを LINE やメールで送れる。
    受け取った人がリンクを開くと確認画面が出て、その人の端末に読み込まれる
  - データはリンクの `#` 以降に圧縮して入れているため、サーバー (GitHub Pages) には送られず保存もされない。
    内容を更新したら、もう一度リンクを送る
  - ホーム画面に追加したアプリで読み込むときは、リンクをコピーして「データを貼り付け」に貼り付ける
  - **ファイルを送る**: `.json` ファイルを共有メニューで送り、受け取った人は「ファイルを開く」で読み込む

## 使い方

GitHub Pages (main への push で `.github/workflows/pages.yml` が自動公開: https://asanoelc0.github.io/trip-receipt/ ) などの HTTPS で公開し、スマホのブラウザで開いて「ホーム画面に追加」すると
アプリのように起動できます (Service Worker によりオフラインでも起動)。

ローカルで試す場合:

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
